
# SSJCET CodeCampus 🎓

### A Web Technology Project for SSJCET Computer Engineering Department

**SSJCET CodeCampus** is a web-based academic dashboard developed as a college Web Technology project for the Computer Engineering Department of Shivajirao S. Jondhale College of Engineering (SSJCET).

The website provides a centralized interface for viewing academic information such as attendance, marks, assignments, timetables, notices, and department members. It is designed with a simple navigation system and a responsive, user-friendly interface.

🌐 **Live Website:** https://omshinde05.github.io/SSJCET-Codecampus/

📂 **GitHub Repository:** https://github.com/Omshinde05/SSJCET-Codecampus

---

## 📌 Project Overview

The purpose of SSJCET CodeCampus is to demonstrate how front-end web technologies can be used to build an academic dashboard.

The project brings multiple academic sections together in one interface, making it suitable for demonstrating website structure, styling, JavaScript functionality, and user interface design.

## ✨ Features

- **Dashboard** — Overview of academic information.
- **Attendance** — View attendance information.
- **Marks** — Display academic marks.
- **Assignments** — View assignment information.
- **Timetable** — View the class timetable.
- **Notices** — Display academic announcements.
- **People** — View department members and related information.
- **Approvals** — Demonstration interface for approval-related actions.
- **Settings** — Access available application settings.
- **Dark Mode** — Switch between light and dark themes.
- **Interactive Interface** — Navigation, buttons, forms, and dialogs.
- **Responsive Design** — Designed to be usable on desktop and mobile screens.

> Note: This is a front-end demonstration project. Academic records and interactive features may use sample data. A backend and database are not included in the current version.

## 🚀 Getting Started

### Prerequisites

You need:

- A computer with a modern web browser.
- A code editor such as Visual Studio Code.
- The project source files.

### Installation

**1. Clone the repository**

Open a terminal and run:

```bash
git clone https://github.com/Omshinde05/SSJCET-Codecampus.git
```

**2. Open the project folder**

```bash
cd SSJCET-Codecampus
```

**3. Open the project**

Open the folder in Visual Studio Code.

**4. Run the website**

Open `index.html` in your browser, or use the Live Server extension in VS Code.

## 🌐 Deployment

The project is hosted using GitHub Pages.

Visit the live website:

**https://omshinde05.github.io/SSJCET-Codecampus/**

To publish updates, commit the updated files to the configured `main` branch and allow GitHub Pages to rebuild the website.
